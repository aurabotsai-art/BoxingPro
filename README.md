# BoxingPro

BoxingPro is a boxing training and coaching platform — workout programs, technique drills, progress tracking, and coach/fighter management in one app.

> **Status:** Planning phase. No application code yet — see [`docs/PLANNING.md`](docs/PLANNING.md) for the product plan and [`docs/ROADMAP.md`](docs/ROADMAP.md) for the build order.

## Repository layout

```
docs/
  PLANNING.md      Product vision, target users, feature scope, open questions
  ROADMAP.md       Phased milestones from MVP to launch
  ARCHITECTURE.md  Proposed tech stack and system design
CLAUDE.md          Context for AI-assisted development sessions
```

## Proposed stack (subject to confirmation)

- **Frontend:** Next.js (App Router) + TypeScript + Tailwind CSS
- **Backend / DB / Auth:** Supabase (Postgres, Auth, Storage, Edge Functions)
- **Hosting:** Vercel
